MMPose 与 Whisper 可使用不同的 Python 环境，由 recognition.local.json 指定。支持本机或 SSH 服务器，不在网页输入密码。

从视频和录音开始
在单独的识别环境安装 MMPose 与 WhisperX，并编辑本地 config.ini。工具沿用已有的逐步运行入口。
python adualnet.py pipeline --config config.ini --step gait-recognition --dry-run
python adualnet.py pipeline --config config.ini --step speech-recognition --dry-run
确认命令、模型权重和路径后，去掉 --dry-run 执行。GPU 与模型下载需求由识别环境决定。
识别后的人工核查
检查姿态追踪对象、关键点质量、帧率和空间单位。核查语音转录、说话人及回答时间，再标注回答正确性。
python adualnet.py reviewed-speech --tasks tasks.csv --responses responses.csv --out reviewed_speech.csv
reviewed-speech 按人工注释计数，保留真实错误，不做预期序列吸附、计数下限或时间偏移。其新测量定义与历史稿件输入分版本保存。
详见 docs/toolkit_guide_zh.md 的输入模板与提取步骤。提取结果需人工核对并整理成同一张特征表。

展示方法与测量边界，不预设新队列的模型性能。


01 / POSE
步态测量
人体关键点、踝部事件估计、图像空间位移与时间特征，并保留技术 QC。
像素量不等于米制步长；足接触相位指标暂不提供。


02 / SPEECH
语音任务
转录经人工整理为真实回答，生成计数、正确率与首答延迟等八项指标。
保留真实错误；评分规则由研究者明确记录。


03 / MODELLING
队列建模
AdaBoost、RF、SVM、DT；训练折内筛选、特征域消融与条件 bootstrap 区间。
需独立的队列特征表；不会自动对单段视频给出诊断。




使用与数据处理说明
先使用合成演示熟悉流程，再处理经授权的研究录像。请核对人物、关键点、任务时窗和逐条回答，记录评分规则，完成两项确认后导出。
远程识别会把视频和音频传至配置的服务器，两端均保留副本。研究用途，不提供临床诊断。
图像空间测量不等同于米制步长；足接触相位尚未建立，相关指标保持缺失。人工确认不代表生理准确性或临床有效性已获验证。


输入与核查保存在本地 local_workspace；远程识别服务器也保留传输副本。公开代码包不包含这些数据。
